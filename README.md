# Cat's Working Days
Arduboy Arcade game about a really hardworking programmer kitty!

## Концепция

Котик-программист отбивается хвостом-щитом от рабочего хаоса, который летит в него по осям X и Y — багов, созвонов, дедлайнов и прочих неприятностей рабочего дня. Игра выполнена в честь Дня программиста и вдохновлена боем с Андайн (Undyne) из Undertale: важно не просто уворачиваться, а вовремя направлять щит в сторону угрозы.

## Управление
4 стрелки - разворачивают хвост в соответствущую сторону
Кнопка А - активирует способность, пару секунд неуязвимости
Кнопка В - WIP

## Геймдизайн

**Здоровье**: 3 сердечка. Каждый пропущенный снаряд отнимает одно сердечко.
**Уровни сложности**: 3, идут по возрастанию. Уровень пройден — автоматический переход на следующий, сложность растёт за счёт скорости и плотности снарядов.
**Способность кота**: кратковременная неуязвимость по кнопке A
**Звуковые эффекты**: реакция на блок, попадание, смену уровня и результат игры.
**Очки**: начисляются за каждый успешно заблокированный снаряд и за выживание на более высоких уровнях сложности.
